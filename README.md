# ThunderCheck
Telegram bot for checking messages using AI

# How to use
1. Create telegram bot, copy token and paste in config.py
2. Create GROQ API key and paste it to config.py
3. Get your proxy URL (GROQ is not available in Russia); Fork this repository to remove the proxy setting
4. Install requirements from requirements.txt
5. Start bot (python3 main.py)
